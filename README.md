# アクアのGrok ToDo♡

Grokと一緒に作った、シンプルで可愛いToDoアプリです。

Python初心者が、Grokと対話しながら完成させました。

## スクリーンショット

![スクリーンショット](https://github.com/aqua-grok/aqua-grok-todo/blob/main/screenshot.png)

## 特徴

- タスク追加（優先度：高・中・低）
- 期限設定（YYYY-MM-DD）
- 完了処理（✓マーク付き）
- 削除機能
- 自動保存・読み込み（テキストファイル）
- Enterキーで追加可能
- 優しい水色のUI

## 技術スタック

- Python 3.x
- tkinter（標準ライブラリのみ使用）
- 外部ライブラリなし

## ダウンロード

最新版のEXEはこちらからダウンロードできます。

→ [Releases](https://github.com/aqua-grok/aqua-grok-todo/releases/tag/v1.0.0)

## 使い方

1. ダウンロードした `aqua_grok_todo.exe` を実行
2. タスクを入力して「追加」ボタン（またはEnterキー）
3. 優先度と期限を設定（任意）
4. 完了したいタスクを選択して「完了」
5. 不要なタスクは「削除」
