# アクアのGrok ToDo♡

Grokと一緒に作った、シンプルで可愛いToDoアプリです。

## 特徴
- タスク追加（優先度：高・中・低）
- 期限設定
- 完了（✓マーク）・削除
- 自動保存（テキストファイル）
- 優しい水色のUI

## 技術
- Python 3.x
- tkinter（標準ライブラリのみ）

## 使い方
1. `aqua_grok_todo.exe` を実行
2. タスクを入力して追加
3. 完了・削除で管理
